## Structure du dépôt
```
docs/
├── volet1-agile/          → exports Jira, registre des risques, bilan de contribution
├── volet2-architecture/   → diagrammes, dimensionnement, décisions, exports Figma
└── volet3-qualite/        → plan de tests, sécurité, observabilité, maintenance
rapport-final/             → version consolidée à remettre sur Moodle
```

## Convention de branches
- `main` : protégée, ne reçoit que du code/docs validés par Pull Request
- une branche par personne pour le travail en cours (voir CONTRIBUTING.md)

## Convention de commits
`<volet>: <action réalisée>` — ex. `volet2: ajout diagramme de séquence réservation siège`
Un commit par avancée réelle, même petite. Pas de gros commit unique en fin de projet.
