## Lecture collective

Les responsabilités principales n'impliquent pas un cloisonnement strict. La revue des Pull Requests et les décisions d'architecture ont été réalisées collectivement. L'équipe ne maîtrisait pas parfaitement GitHub au démarrage, mais son utilisation s'est structurée au fil du projet : branches individuelles, Pull Requests, commentaires, approbations et fusions vers `main`.
