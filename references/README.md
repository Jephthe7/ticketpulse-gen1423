# Références

Centraliser ici tout ce qui sera cité dans le rapport :
- Énoncé du projet (Projet_GEN1423.pdf)
- Notes de cours pertinentes (architecture, dimensionnement, sécurité, agilité)
- Normes ou standards cités (ex. PCI DSS si mentionné pour le paiement)

Un lien ou une référence complète par élément — évite les hypothèses "parce qu'on le pense" non traçables.
